# 舆情事件字典（Opinion Corpus）

本文件定义伊利液态奶供应链 6 节点相关的舆情事件字典，供 LLM 多智能体语义测度与后续 Pearson 收敛效度检验使用。

- **时间窗口**：2025-09-01 至 2026-09-30（窗口外事件不纳入）
- **事件级样本量**：12 条（≥ 12，满足收敛效度检验最低要求）
- **数据来源声明**：E001、E004 来自已确认的公开报道；E005–E014 为基于行业常见风险情景构造的示例事件，用于算法验证与流程走通，具体报道细节未经独立核实，不声称代表真实发生的新闻。

---

## 一、字段定义

| 字段 | 类型 | 说明 |
|:-----|:-----|:-----|
| event_id | string | 事件唯一标识，格式 `E序号-日期-来源` |
| node | string | 关联拓扑节点 ID（N1–N6） |
| source | string | 报道来源媒体 |
| date | string | 事件日期（ISO 8601） |
| 原文 | string | 报道原文摘录 |
| scope_word | string | 影响范围词：`全局` / `区域` / `局部` |
| time_decay_flag | bool | 是否启用时间衰减：`true`=脉冲式舆情（影响随时间衰减）；`false`=持续性/结构性风险（不衰减） |

## 四、事件严重度评分

严重度评分标准（供 LLM 语义测度参考，0–1 归一化）：

| 维度 | 权重 | 评分要点 |
|:-----|:----:|:---------|
| 影响范围（scope_word） | 0.4 | 全局=1.0，区域=0.6，局部=0.3 |
| 持续性（time_decay_flag） | 0.3 | false（不衰减/结构性）=1.0，true（脉冲式）=0.5 |
| 量化冲击幅度 | 0.3 | 按原文量化描述映射：如"下降15%"→0.6，"激增2.3倍"→0.7 等 |

> 注：具体评分由 LLM 智能体在语义测度阶段生成，本表仅提供基准锚点。
